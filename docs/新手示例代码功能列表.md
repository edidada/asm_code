# 新手示例代码功能列表

本项目是一套面向新手的 **Linux x86（AT&T 语法）汇编示例集**，全部示例：

- 使用 `int $0x80` 软中断直接调用 Linux 内核（32 位系统调用 ABI），**不依赖 C 库**；
- 入口均为 `_start`，结构统一：准备寄存器参数 → `int $0x80` → 处理结果；
- 每个示例都配有 CI 自动验证：stdout 逐字节比对 + 可选退出码比对，保证示例永远可运行、可验证。

> 系统调用参数约定（`int $0x80`）：`%eax`=调用号，`%ebx`/`%ecx`/`%edx`=第 1/2/3 个参数，返回值在 `%eax`。
> 本集仅用到 3 个调用：`sys_write(4)`、`sys_read(3)`、`sys_exit(1)`。

## 一、示例功能列表（按学习顺序）

| # | 文件 | 功能 | 涉及知识点 | 预期结果 |
| --- | --- | --- | --- | --- |
| 1 | `examples/01-hello.s` | 在屏幕输出 `Hello World!` 并正常退出 | 数据段定义、`.ascii`+`.byte` 拼字符串、`len = . - msg` 求长度、sys_write / sys_exit | 输出 `Hello World!`，退出码 0 |
| 2 | `examples/02-exit-code.s` | 不做任何输出，以退出码 42 结束进程 | sys_exit 与退出码、shell 中 `echo $?` 的来源 | 无输出，退出码 42 |
| 3 | `examples/03-echo.s` | 读取标准输入并原样回显 | sys_read、`.lcomm` 在 .bss 定义缓冲区、用返回值（实际字节数）做参数 | 输入什么就输出什么 |
| 4 | `examples/04-count.s` | 循环打印 1 到 5，每行一个 | 内存变量做计数器、`cmpl`/`jg` 条件跳转、`jmp` 回跳、数字→ASCII（+48） | 输出 `1` `2` `3` `4` `5` 各占一行 |
| 5 | `examples/05-sum.s` | 计算 `1+2+...+10=55` 并打印结果 | 循环累加、`divl` 除法（商/余数）、多位数拆成十位+个位转 ASCII | 输出 `55` |
| 6 | `examples/06-upper.s` | 把字符串中的小写字母转成大写后输出 | 寄存器间接寻址 `(%esi)`、无符号比较 `jb`/`ja`、同一字母大小写 ASCII 相差 32 | `Hello, ASM! 123` → `HELLO, ASM! 123` |
| 7 | `examples/07-reverse.s` | 原地反转字符串 `abcdef` → `fedcba` | 双指针算法、两端向中间交换、表达式地址 `$str+rlen-1` | 输出 `fedcba` |

## 二、建议学习路径

```
01-hello  →  02-exit-code  →  03-echo  →  04-count  →  05-sum  →  06-upper  →  07-reverse
(第一个程序)  (进程退出)      (读输入)   (循环+字符)  (算术+除法)  (间接寻址)  (双指针)
```

1. 先读懂 `01`：理解「段、符号、寄存器传参、软中断」四件事；
2. `02` 理解进程退出码如何被父进程（shell）观察；
3. `03` 有了输入，程序才算「活」了；
4. `04`/`05` 掌握循环与算术，并学会把数字变成可打印字符（汇编里数字和字符是两回事）；
5. `06`/`07` 进入内存寻址与经典算法，为后续更复杂的程序打底。

## 三、如何本地构建运行（Linux 环境）

每个示例的构建方式相同，以 `01-hello` 为例：

```bash
# 汇编：.s -> 目标文件 .o
as -o 01-hello.o examples/01-hello.s
# 链接：.o -> 可执行文件
ld -o 01-hello 01-hello.o
# 运行
./01-hello              # 输出 Hello World!

# 示例 2 的退出码可以这样观察：
./02-exit-code; echo $?      # 输出 42

# 示例 3 可以手动喂输入：
echo "hi" | ./03-echo        # 输出 hi
```

> 注意：仓库通过 `.gitignore` 忽略 `hello`/`*.o` 等构建产物，本地构建生成的文件不会进入版本库。

## 四、CI 如何自动验证全部示例

`.github/workflows/blank.yml` 会遍历 `examples/*.s`，逐个执行：

```
as 汇编 → ld 链接 → 运行 → 与预期文件比对
```

预期文件约定（与示例同名前缀，全部在 `examples/` 下）：

| 文件 | 必需？ | 作用 |
| --- | --- | --- |
| `<name>.expected` | 必需 | 预期 stdout 内容，与程序输出**逐字节 diff** |
| `<name>.stdin` | 可选 | 存在则重定向为程序的标准输入 |
| `<name>.rc` | 可选 | 预期退出码（缺省 0），与实际退出码比对 |

任一示例汇编失败、链接失败、输出不符或退出码不符，CI 即失败；全部通过则输出 `ALL EXAMPLES PASSED`。

新增示例只需三步：写 `examples/08-xxx.s` → 放一个 `08-xxx.expected` → 推送，CI 自动纳入测试。

## 五、给新手的两个提醒

- **数字 ≠ 字符**：内存里的 `5` 是数值 5，屏幕上的 `5` 是 ASCII 48，所以打印前要 `+48`（见示例 4、5）。
- **字符串长度自己管**：`.ascii` 不会像 C 那样自动补 `\0`，程序靠 `len = . - msg` 在汇编期算出长度；用 `.string` 时它会补 `\0`，且转义写法容易踩坑（`\n` 写成 `\\n` 会输出字面反斜杠 n）。

## 六、数据结构模块（模仿 tbox）

`ds/` 目录模仿 [tbox](https://github.com/tboox/tbox) 的基础容器，用汇编实现了一套"无 libc 版"数据结构：由于没有 malloc，全部使用 `.bss` 静态内存池（思路与 tbox 的固定内存池一致）；链表/哈希的节点分配用**空闲链（free list）**模拟 malloc/free。每个文件自带 API 函数与测试 `_start`，CI 会编译运行并逐字节比对输出。

| 文件 | 对应 tbox | 功能 | 测试验证点 |
| --- | --- | --- | --- |
| `ds/vector.s` | `tb_vector_t` | 动态数组：init / push / pop / at / size | 尾部追加后按序读回；pop 返回尾元素且 size 减 1 |
| `ds/stack.s` | `tb_stack_t` | 栈（LIFO）：init / push / pop | 入栈 1..5，出栈顺序为 5..1 |
| `ds/queue.s` | `tb_queue_t` | 队列（FIFO，8 槽环形缓冲） | 先进先出顺序；入队越过尾部时 head/tail 正确回绕 |
| `ds/list.s` | `tb_list_t` | 单链表：尾部追加 / 按值删除 / 遍历 | 删除中间节点后链不断；释放的节点可被复用 |
| `ds/hash.s` | `tb_hash_t` | 哈希表（8 桶，链地址法，`key & 7`） | 命中返回值；同桶冲突（key=1 与 9）都能查到；未插入返回 miss |
| `ds/string.s` | `tb_string_t` | 动态字符串：append / length / at | 多次追加拼接正确；长度与随机访问正确；容量不足自动截断 |

统一内部调用约定（`ds/` 全部文件一致）：参数 `edi/esi/edx`，返回 `eax`，被调方保存 `ebx/esi/edi/ebp`（`int $0x80` 本身只占用 eax 作返回值，其余寄存器内核自动保存恢复）。

校验文件与 `examples/` 相同：每个程序一个 `<name>.expected`，CI 运行后逐字节 diff。
