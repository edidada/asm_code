# 代码功能说明

本项目是一个 **Linux x86 32 位汇编语言（AT&T 语法）** 示例工程，核心功能是在终端屏幕上输出字符串 `Hello World!` 并正常退出。

参考教程：
- 《Linux 汇编语言开发指南》：https://zhuanlan.zhihu.com/p/54853591
- IBM developerWorks《Linux 下汇编语言开发》：https://www.ibm.com/developerworks/cn/linux/l-assembly/index.html

## 一、文件结构

| 文件 | 说明 |
| --- | --- |
| `hello.s` | 汇编源代码（AT&T 格式，可读文本） |
| `hello.o` | 由 `hello.s` 汇编生成的 **目标文件**（机器码，不可直接阅读） |
| `hello` | 由 `hello.o` 链接生成的 **可执行文件**（运行后输出 `Hello World!`） |

| `.github/workflows/blank.yml` | GitHub Actions 的持续集成工作流（目前仅演示用，未实际编译汇编） |

## 二、核心代码：`hello.s` 逐行解析

`hello.s` 使用 Linux 传统的 **`int $0x80` 软中断** 方式发起系统调用（32 位系统调用接口）。代码分为两个段：**数据段（`.data`）** 与 **代码段（`.text`）**。

### 1. 数据段（`.data`）

```asm
.data    # 数据段声明
         msg : .string "Hello World!\n"       # 要输出的字符串
         len = . - msg                         # 字符串长度
```

- `msg`：定义并初始化一个字符串 `"Hello World!\n"`。
- `len = . - msg`：`.` 表示当前地址计数器的值，`msg` 是该字符串的起始地址，二者相减即得到字符串的字节长度，保存在符号常量 `len` 中。

### 2. 代码段（`.text`）

```asm
.text                   # 代码段声明
.global _start          # 指定入口函数

_start:                 # 程序入口（链接器默认从此处开始执行）
```

- `.text`：声明代码段。
- `.global _start`：将 `_start` 声明为全局符号，作为程序的入口点（链接器需要这个名字）。

### 3. 第一个系统调用 —— `sys_write` 输出字符串

```asm
       movl $len, %edx  # 参数三：字符串长度
       movl $msg, %ecx  # 参数二：要显示的字符串地址
       movl $1, %ebx    # 参数一：文件描述符（1 = stdout 标准输出）
       movl $4, %eax    # 系统调用号（4 = sys_write）
       int  $0x80       # 触发软中断，陷入内核执行 sys_write
```

`int $0x80` 的 32 位系统调用参数约定为：

| 寄存器 | 含义 | 本例取值 |
| --- | --- | --- |
| `%eax` | 系统调用号 | `4`（`sys_write`） |
| `%ebx` | 参数 1 | `1`（文件描述符 `stdout`） |
| `%ecx` | 参数 2 | `msg`（字符串地址） |
| `%edx` | 参数 3 | `len`（字符串长度） |

即执行 `write(1, msg, len)`，把字符串写到标准输出。

### 4. 第二个系统调用 —— `sys_exit` 退出程序

```asm
       movl $0, %ebx    # 参数一：退出码（0 表示正常退出）
       movl $1, %eax    # 系统调用号（1 = sys_exit）
       int  $0x80       # 触发软中断，陷入内核结束进程
```

| 寄存器 | 含义 | 本例取值 |
| --- | --- | --- |
| `%eax` | 系统调用号 | `1`（`sys_exit`） |
| `%ebx` | 参数 1 | `0`（退出码） |

即执行 `exit(0)`。`sys_exit` 不返回，程序到此终止。

> 注意：由于直接调用 `sys_exit` 而非 C 库的 `exit()`，程序 **不依赖 libc**，是一个“裸”系统调用程序，因此无需 `main` 函数，入口就是 `_start`。

## 三、构建与运行（在 Linux 环境）

```bash
# 1. 汇编：把 .s 源文件编译为目标文件
as -o hello.o hello.s

# 2. 链接：把目标文件链接为可执行文件
ld -o hello hello.o

# 3. 运行
./hello
# 输出：Hello World!
```

各文件对应关系：

```
hello.s  --(as 汇编)-->  hello.o  --(ld 链接)-->  hello (可执行)
```

## 四、CI 工作流说明

`.github/workflows/blank.yml` 是一个 GitHub Actions 模板：在 `master` 分支发生 `push`/`pull_request` 时触发，运行环境为 `ubuntu-latest`，目前仅执行 `echo` 演示命令，**尚未集成对 `hello.s` 的自动汇编/链接/运行**。如需让 CI 真正校验汇编代码，可在 `build` job 的 steps 中加入：

```yaml
      - name: Assemble and run
        run: |
          as -o hello.o hello.s
          ld -o hello hello.o
          ./hello
```

## 五、小结

- 这是一份最精简的 Linux 汇编入门程序，演示了 **数据/代码段划分**、**符号常量求长度** 以及 **通过 `int $0x80` 调用内核的 `sys_write`/`sys_exit`**。
- 它不依赖任何 C 库，全程通过系统调用与内核交互，是理解“程序如何与操作系统对话”的典型起点。
